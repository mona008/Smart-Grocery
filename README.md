# 🛒 Smart Grocery – Grocery, Meal & Budget Planner

A web-based **Grocery, Meal, Pantry, Budget, and Expense Management System** developed using **PHP and MySQL**.

Smart Grocery helps users manage grocery items, pantry inventory, meal planning, shopping lists, budgets, and expenses in one centralized application.

## ✨ Features

* 🔐 **User Authentication**

  * User registration and login
  * Session-based authentication
  * Logout functionality

* 🛍️ **Grocery Management**

  * Add and manage grocery items
  * Maintain grocery price information

* 🏠 **Pantry Management**

  * Track pantry items
  * Manage item quantities

* 🍽️ **Meal Planning**

  * Create and manage meals
  * Add meal ingredients
  * Plan meals

* 📝 **Shopping List**

  * Create shopping lists
  * Add and manage grocery items

* 💰 **Budget Management**

  * Set grocery budgets
  * Manage weekly budgets
  * Monitor spending

* 💳 **Expense Tracking**

  * Record grocery expenses
  * Track household spending

* 👤 **Profile Management**

  * View and manage profile information

* 📊 **Dashboard**

  * Centralized overview of grocery, budget, and expense information

## 🗄️ Database

The project uses **MySQL** with the database:

`grocery_planner`

The database includes tables for:

* Users
* Budgets
* Weekly Budgets
* Grocery Items
* Grocery Prices
* Pantry
* Meals
* Meal Ingredients
* Meal Plans
* Shopping Lists
* Shopping List Items
* Expenses

### Database Files

database/
├── schema.sql
└── seed.sql

* `schema.sql` → Creates the database structure.
* `seed.sql` → Inserts sample grocery items and prices.
